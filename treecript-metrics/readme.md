### [treecript](https://github.com/inab/treecript) metrics namespace

Namespace which includes terms used to describe metrics gathered
by [treecript](https://github.com/inab/treecript), so they can be
pointed out from propertyID from PropertyValue within resourceUsage associated to CreateAction / ActivateAction
